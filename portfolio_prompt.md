### 📝 Prompt for Portfolio Landing Page

*"Build me a clean, modern, single-page portfolio website that brands me as a professional blending **programming + Photoshop expertise**. The site should have these sections:*

1. **Hero Section**

   * Headline: “Blending Code + Creativity”
   * Subheadline: “I build custom scripts, plugins, and automation workflows that combine programming and Photoshop to help businesses save time and scale design.”
   * Call-to-Action button: “Work With Me” (scrolls to contact form).
   * Visual: subtle animation, abstract code/design blend background.

2. **About Me**

   * Short intro: “I’m a full-stack developer and Photoshop power user. My unique blend of coding and creative skills allows me to create automation scripts, design tools, and workflows that solve real business problems.”
   * Skills list (Programming: JavaScript, React, Node.js; Creative: Photoshop scripting, automation, plugin development).

3. **Case Studies / Projects**

   * Use card layout or grid with thumbnails + short descriptions.
   * Example projects:

     * “Etsy Mockup Automation – 1 template → 100 products”
     * “Real Estate Photo Workflow – watermark + resize 200 photos in minutes”
     * “Ad Banner Generator – multiple sizes auto-created from one design”
   * Each case study links to a short video demo or GIF.

4. **Video Demo Section**

   * Embedded short clips (30–60 seconds each) showing before/after automation.
   * Headline: “See My Work in Action.”

5. **Testimonials / Results**

   * Quote-style boxes (if no real clients yet, use hypothetical “Etsy Seller” / “Agency Designer” perspectives).
   * Example: *“This script saved me 6 hours of manual work every product launch.”*

6. **Contact Section**

   * Headline: “Let’s Build Something”
   * Subheadline: “Need a developer who understands design workflows? Let’s talk.”
   * Contact form (Name, Email, Message).
   * Email button: “Send me an email directly.”

*Design guidelines:*

* Modern, minimal, developer–designer vibe (white background, accent color like deep blue or orange).
* Use big bold typography for headlines.
* Rounded buttons, soft shadows, clean grid layout.
* Responsive for mobile and desktop.
* Optional dark mode toggle."
